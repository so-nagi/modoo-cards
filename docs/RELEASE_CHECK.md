# 공개본 검증 기록

기준일: 2026-10-07. 운영 코드에서 개인 설정·자료·비공개 Git 이력을 제외하여 별도 소스 이력으로 구성했습니다.

## 확인한 사항

- 운영 화면의 JavaScript 파일과 해당 기준 커밋의 배포 산출물 SHA-256 일치.
- Node.js 기능·통합 검사 **142개 통과**.
- Python 백엔드 검사 **153개 통과**. Starlette의 httpx 관련 사용 중단 경고 1건이 있으며 실패는 없습니다.
- 새 폴더에서 `npm ci` 후 TypeScript 검사와 Vite 프로덕션 빌드 통과.
- 합성 Firebase 설정으로 `npm run setup`과 `npm run build:hosting` 실행. 생성된 번들의 API·소스 저장소 주소가 입력값과 일치함을 확인. 실제 클라우드 접속은 수행하지 않음.
- 설정 생성 도구가 잘못된 프로젝트·서비스 계정 키·기존 파일 덮어쓰기를 거절하는지 검사했고 통과했습니다.
- 원본 효과음 7개의 해시, 파생 음원의 PCM·정규화·파형 검사 통과.
- 별도 로컬 컬렉션으로 브라우저 실행. 빈 덱 화면, Pretendard 적용, 소스 코드 링크, 가로 넘침 없음을 확인.
- 공개 파일 검사에서 자격증명 패턴, 기존 설치 식별자, 개인 데이터 경로가 검출되지 않음. 추적된 파일과 소스 폴더를 함께 확인하는 제한된 검사이며 전체 보안 감사를 의미하지 않음.
- 배포 산출물에 Pretendard와 OCR 모델의 라이선스 문서가 포함됨을 확인.

## 확인하지 않은 사항

- 이 공개본으로 새 Firebase·Render 계정을 만들어 처음부터 배포하는 과정. 안내서는 현재 코드 경로와 공급자의 공식 문서를 대조하여 작성했습니다.
- 이 공개본의 Docker 이미지 전체 빌드와 실제 Render 재배포.
- 모든 기기·브라우저·스크린리더 조합.
- 대규모 이용자·대용량 컬렉션 운영. 무료 사용량 안에서 개인이 설치하는 구성을 안내합니다.

## 공개 범위

클래식 스킨만 포함합니다. 다른 스킨의 선택 메뉴·CSS·카드 렌더링 코드와 해당 전용 테스트는 제외했습니다. 이전 설정 파일에 다른 스킨 값이 있어도 클래식으로 표시하며 포인트색·글자 크기·학습 데이터는 보존합니다. 공개 파일 검사에도 제외 스킨의 렌더링 코드가 다시 포함되지 않도록 검사를 추가했습니다.

개인 덱·복습 기록·Firebase 설정·로그·캐시·개인 파일 경로·이전 비공개 Git 이력은 포함하지 않습니다. 재배포 근거를 확보하지 못한 HJSS 글꼴과 종이 이미지, 사용하지 않는 Cherry 음원도 제외했습니다. 기본 글꼴은 Pretendard이며 기존 운영 서비스의 글꼴이나 자료를 변경하는 작업은 아닙니다.

자동 검증 명령과 CI 구성은 저장소에 포함되어 있습니다. GitHub Actions 실행 결과는 해당 커밋의 Actions 화면에서 별도로 확인하세요.

- 화면의 남는 높이에 맞춰 카드 영역을 조절해 정답 보기와 평가 버튼을 하단 메뉴 위에 배치합니다. 긴 카드 내용은 카드 내부에서 스크롤합니다.
- 브라우저의 390×740, 375×667, 320×568 화면에서 질문·정답 상태의 버튼 위치를 확인했습니다. 1280px 데스크톱에서는 기존 330px 카드 높이를 유지합니다. 실제 휴대전화 검증은 별도입니다.
- 기존 프런트엔드 검사 142개와 프로덕션 빌드가 통과했습니다.
