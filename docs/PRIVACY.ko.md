# 데이터가 저장되는 곳

이 저장소의 개발자에게 덱이나 Google 로그인 토큰을 보내는 기능은 없습니다. 설치자는 본인 Firebase 프로젝트와 API 서버 주소를 설정합니다. 소스를 수정한 배포본이나 설정한 외부 서버의 행동은 별도로 확인해야 합니다.

- Google 로그인은 본인 Firebase Authentication을 사용합니다. 브라우저에서 받은 ID 토큰은 지정한 Anki 서버가 서명·프로젝트·유효기간을 검증합니다.
- 덱·노트·복습·미디어는 계정별로 본인 Realtime Database에 저장됩니다. API 서버는 작업 중 이 자료를 읽고 임시 파일 캐시를 사용하므로 서버 운영자도 신뢰할 수 있어야 합니다.
- 화면 설정은 본인 Firestore의 사용자 경로에도 사본이 저장됩니다.
- OCR은 포함된 한영 모델로 브라우저에서 수행합니다. 확인하고 등록한 내용은 API 서버로 전송됩니다. 이미지 가리기 카드로 저장한 사진은 카드 미디어로 서버·RTDB에 저장됩니다.
- TTS는 브라우저와 OS의 음성 기능을 사용합니다. 선택한 음성이 원격 서비스형인지 여부는 브라우저·OS의 정책을 확인하세요.
- 다른 사람의 Firebase·Render 설정을 복사하면 그 사람이 운영하는 저장소·서버를 사용하게 됩니다. 설치 안내서의 예시는 본인 값으로 바꿔야 합니다.

계정별 규칙은 다른 일반 이용자의 접근을 제한합니다. Firebase 프로젝트 관리자와 서버 운영자의 권한을 제한하는 종단간 암호화 구조는 아닙니다. 별도의 분석 SDK 초기화나 광고 추적은 포함하지 않습니다.
