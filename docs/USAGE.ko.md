# 카드 작성·가져오기·백업

## 카드 작성

상단 ADD에서 덱과 노트 유형을 고릅니다. Basic은 앞면 질문과 뒷면 정답을 입력합니다. Cloze는 문장에서 숨길 부분을 선택하여 빈칸으로 만들고 같은 문제 또는 새 문제로 묶습니다. 기본 앞면은 음영 안의 언더바 한 개가 한 글자에 해당합니다. 공백은 단어 경계로 남고 블록 위에 마우스를 올리면 글자 수가 표시됩니다.

HTML 원문 버튼으로 `<b>강조</b>`, `<br>` 등의 서식을 직접 편집할 수 있습니다. Cloze 원문은 `대한민국의 수도는 {{c1::서울::도시 이름}}입니다.`와 같습니다. 입력을 HTML로 보존하므로 Anki 패키지로 내보낼 수 있습니다. 작성 화면의 만드는 방법 탭에 더 많은 예시가 있습니다.

이미지 가리기는 이미지에서 사각형을 그립니다. 선택한 박스의 모서리를 움직여 크기를 바꾸고 중앙을 잡아 이동합니다. 그룹은 한 번에 정답을 공개할 박스 단위입니다. Ctrl+Z 실행 취소, 확대·이동·자르기·회전을 지원합니다. 저장 전에 옆 미리보기의 앞면·뒷면을 확인합니다.

## 파일 종류 선택

| 파일 | 앱에서 사용하는 방식 |
|---|---|
| TSV/CSV | 단어·뜻 행을 확인하고 선택하여 추가 |
| APKG | 기본 UI는 내용만 가져오기. 원본 카드 디자인·미디어·기존 학습 일정·덱 옵션을 가져오지 않음 |
| COLPKG | 전체 컬렉션 복원. 현재 컬렉션이 교체될 수 있으므로 먼저 백업 |

**APKG 내용 가져오기는 미디어 카드의 완전한 이전 수단이 아닙니다.** HTML/CSS 템플릿은 기본 필드 표시로 정리합니다. 일반 어휘 카드의 필드와 덱 구조를 가져오는 용도입니다. 원본 필드 문자열, 노트 식별 정보와 카드 템플릿 개수·순서는 유지하며 재가져오기 시 중복을 식별합니다. Cloze 같은 유형의 특성은 가능한 범위에서 유지합니다.

서버의 원본 호환 `/api/import`는 그대로 존재하지만 기본 APKG 화면은 `/api/import-content`를 사용합니다. 오류가 났을 때 자동으로 다른 방식으로 가져오지 않습니다.

원본 서식·미디어·복습 기록까지 옮기려면 Anki에서 전체 컬렉션을 내보낸 `.colpkg`를 사용합니다. 내보내기 옵션에서 미디어 포함 여부를 확인합니다. 빈 새 설치에서 먼저 복원하고 확인하세요. 실제 자료가 있는 컬렉션에서 시험 복원을 하지 않습니다.

## 정기 백업

앱의 가져오기·내보내기에서 전체 컬렉션을 COLPKG로 내려받습니다. 서버 업데이트·프로젝트 이전·보안 규칙 변경 전에 따로 보관합니다. RTDB 동기화는 실수로 삭제한 자료를 항상 되돌리는 버전별 백업을 대신하지 않습니다.

다른 Firebase 프로젝트를 만들면 같은 Google 이메일로 로그인해도 기존 프로젝트의 계정 자료가 자동 이전되지 않습니다. 기존 앱에서 내보내고 새 앱에서 가져와야 합니다. 화면 설정·중요 덱 표시 같은 앱 전용 메타데이터는 Anki 패키지로 모두 이전되지 않을 수 있습니다.

## 지원 범위

AnkiWeb 실시간 양방향 동기화, Python/Qt 애드온 실행, 모든 복잡한 템플릿·MathJax·LaTeX 완전 호환, 오프라인 복습은 제공하지 않습니다. 브라우저 TTS는 OS에 설치된 음성과 브라우저 지원 상태에 따라 달라집니다. OCR은 인쇄된 한영 텍스트 기준이며 결과를 확인한 뒤 등록합니다.
