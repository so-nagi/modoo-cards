# 설치 전에 체험하기

[모두카드 체험판 열기](https://so-nagi.github.io/modoo-cards/)

로그인이나 서버 설정 없이 클래식 화면을 살펴볼 수 있습니다. 영어 기본 카드, 과학 빈칸 카드, 도형 이미지 가리기 샘플 12장이 들어 있습니다.

## 사용 순서

1. 덱을 선택하고 **복습 시작**을 누릅니다.
2. **정답 보기** 또는 Space를 누른 뒤 1~4로 답변합니다. 다시·어려움으로 평가하면 다른 카드 뒤에서 다시 나옵니다. Z로 마지막 답변을 되돌릴 수 있습니다.
3. **ADD**에서 질문과 정답을 직접 입력합니다. 빈칸 카드는 문장을 입력하고 가릴 부분을 선택한 뒤 **선택한 부분을 빈칸으로**를 누릅니다.
4. **사진·파일로 단어 등록**에서 사진 OCR 또는 TSV·CSV 가져오기를 테스트합니다. 추출 결과를 확인하고 저장하세요.
5. **설정 → 샘플 초기화**로 직접 추가한 카드와 기록을 지우고 처음 상태로 돌아갑니다. 초기화 전 JSON 파일로 자료를 보관할 수 있습니다. 이 JSON은 Anki 가져오기 파일이 아닙니다.

## 설치판과의 차이

| 기능 | 체험판 |
| --- | --- |
| 덱 검색·중요 표시·목록/갤러리·편집 | 지원 |
| 기본 카드·텍스트 Cloze 작성·미리보기 | 지원 |
| 사진 OCR·TSV/CSV·붙여넣기 | 브라우저에서 처리 |
| 이미지 가리기 | 샘플 카드 복습만 지원 |
| 복습 | 체험용 반복 순서, 실제 Anki 일정 계산 없음 |
| 기록 | 이 브라우저의 답변 횟수와 분포 |
| Google 로그인·기기 간 동기화 | 설치판에서 지원 |
| 필터 덱·HTML 템플릿·APKG/COLPKG | 설치판에서 지원 |

체험판은 최대 100개 덱, 500장 카드, 최근 2,000개 답변을 저장합니다. 설치판의 카드 HTML 저장 방식이나 공식 Anki 스케줄러는 변경하지 않습니다.

## 자료가 저장되는 곳

체험 자료는 브라우저의 `modoo-cards.demo.v1` 저장 공간에 남습니다. 같은 기기의 같은 브라우저에서는 새로고침 후에도 이어서 볼 수 있습니다. 사이트 데이터 삭제, 시크릿 창 종료, 저장 공간 제한으로 자료가 사라질 수 있습니다. 공용 기기에서는 체험 후 샘플 초기화를 실행하세요.

사진 OCR은 브라우저에서 실행하며 사진·카드 내용을 서버로 전송하지 않습니다. OCR 모델·폰트·음원은 GitHub Pages에서 내려받습니다. 읽어주기는 브라우저·운영체제의 음성 서비스를 사용하므로 선택된 음성에 따라 온라인 처리가 필요할 수 있습니다. 데모의 계정·Anki API 요청은 없습니다.

## 로컬 실행과 배포

```sh
npm ci
npm run dev:demo
```

`http://127.0.0.1:4193/modoo-cards/`를 엽니다. 정적 배포 파일은 `npm run build:demo`로 `dist-demo/`에 생성합니다. 기본 경로는 `/modoo-cards/`입니다. 다른 경로는 `DEMO_BASE_PATH` 환경 변수로 지정합니다.

공식 저장소의 `Publish demo` 워크플로가 GitHub Pages에 체험판만 배포합니다. 복제한 저장소에서는 자동 실행되지 않습니다. 직접 체험판을 배포하려면 워크플로의 저장소 조건과 기본 경로를 바꾸고 Settings → Pages에서 GitHub Actions를 선택하세요. [GitHub 공식 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)

실제 자료를 동기화하려면 [Firebase·서버 설치 안내](SELF_HOSTING.ko.md)를 따르세요.
